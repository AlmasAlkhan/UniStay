# Проверка мобильного клиента UniStay

Дата: 23 октября 2026 года. Ветка: `turar-flutter`. Выполнено локально на Windows, Flutter 3.41.3 / Dart 3.11.1.

| Проверка | Результат |
| --- | --- |
| `flutter analyze` | Без замечаний |
| `flutter test` | 13 тестов пройдены |
| `backend/.venv/Scripts/python.exe mobile/tool/check_backend.py` | Пройден интеграционный сценарий с настоящим Django API |
| `flutter build apk --debug` | Android APK успешно собран |
| `flutter build web --dart-define=API_BASE_URL=https://api.example.com` | Web-сборка успешна; указанный адрес — конфигурационная заглушка |
| `flutter test tool/preview_test.dart` | Снимок синтетического каталога 390 × 844; визуально проверен |

Интеграционный тест использует временную SQLite-базу и отдельные тестовые аккаунты. Проверены профиль, публикация с фото, фильтры, создание заявки, повторная заявка (409), принятие владельцем, раскрытие адреса принятому студенту, соседи, отмена, освобождение места, история и отзыв сессии. Временные данные удаляются после проверки.

Unit/widget-тесты используют HTTP-заглушки. Они отдельно проверяют заголовок Bearer, сохранение фильтров в запросе, разбор ошибок, 401, защищённое хранение через подменяемый интерфейс, истечение сессии, смену сервера и основной путь по интерфейсу.

Нативное защищённое хранилище пока не проверено на устройстве: в unit/widget-тестах используется память. APK собран, но не установлен на физический телефон или эмулятор. iOS на Windows не собирался. Сервис на Mac Алмаса, SMTP и конкурентная работа PostgreSQL этим запуском не проверялись. Backend не изменялся.

APK: `build/app/outputs/flutter-apk/app-debug.apk`. Это debug-сборка для разработки, не подписанный выпуск для магазина. Готовность мобильного клиента не означает, что общий сервер доступен с телефона: его адрес и сетевой доступ нужно настроить согласно README.
